# MongoDB-City-Inspections
This project uses MongoDB to manage and analyze a dataset of city business inspections. The project was completed as part of my database coursework and gave me hands-on experience working with JSON data, MongoDB queries, and CRUD operations.

# Technologies Used
MongoDB
JavaScript
JSON
Linux Terminal
MongoDB Shell

# Note
This project was completed for educational purposes using a course-provided inspection dataset. The screenshots and query file are included to demonstrate the database operations completed during the project.
